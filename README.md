# ➡️ Next Message

유저 입력 없이 **전송 버튼만 눌러도** 이야기가 자연스럽게 이어지게 해주는 SillyTavern 확장입니다.

## 이런 확장이에요

입력창을 비워 둔 채 전송 버튼을 누르면, 확장이 미리 정해 둔 프롬프트를 그 턴의 유저 메시지처럼 끼워 넣어서 전송합니다. 캐릭터는 방금 한 말을 되풀이하지 않고, 마지막 응답에서 바로 이어서 다음 장면을 써 내려갑니다.

끼워 넣은 문장은 이번 요청에만 쓰이는 임시 데이터입니다. 채팅 기록과 메시지 파일에는 아무것도 남지 않아요.

## 기능

**빈 입력 전송 → 이어쓰기**
입력창이 비어 있을 때 전송 버튼을 누르면 동작합니다. 내용을 입력해서 보내면 평소와 똑같이 작동하고, 확장은 개입하지 않아요.

**다시 생성 · 스와이프 지원**
캐릭터의 마지막 응답을 다시 생성하거나 스와이프할 때도 같은 프롬프트가 적용됩니다.

**주입 위치 선택**
프롬프트를 어디에 끼워 넣을지 고를 수 있어요.
- **맨 끝** — 프롬프트 가장 마지막
- **프리필 앞** — 프리필이 있다면 그 바로 앞 (기본값)
- **캐릭터 메세지 뒤** — 캐릭터의 마지막 메시지 바로 뒤

**프롬프트 직접 편집 + 기본값 복원**
이어쓰기에 쓸 문장을 자유롭게 고칠 수 있고, 버튼 하나로 기본 문장으로 되돌릴 수 있어요.

**프롬프트 프리셋**
자주 쓰는 프롬프트에 이름을 붙여 저장하고, 목록에서 골라 쓰고, 지울 수 있어요. 같은 이름으로 저장하면 덮어씁니다.

**상태 표시등**
헤더의 작은 점으로 현재 상태를 바로 알 수 있어요.
- 🟢 켜짐 — 정상 동작
- 🟡 켜져 있지만 프롬프트가 비어 있어 주입되지 않음
- 🔴 꺼짐

**최종 전송본 확인**
실제로 전송되기 직전에 끼워 넣은 문장이 최종 메시지 목록에 들어 있는지 한 번 더 확인합니다. 다른 설정이나 프리셋 때문에 빠졌다면 원래 자리에 다시 넣어 줍니다.

**중복 방지**
끼워 넣을 자리 바로 앞뒤에 이미 같은 문장의 유저 메시지가 있으면 중복 주입을 건너뜁니다.

**그룹 채팅 지원**
그룹 채팅의 라운드 전체에서 빈 입력 전송을 인식해 이어쓰기를 적용합니다.

**실행 기록**
요청마다 무슨 일이 있었는지 시간순으로 보여 주는 기록 창이 있어요. 주입했는지, 어느 위치에 넣었는지, 건너뛰었다면 이유가 무엇인지, 오류가 났다면 어디서 났는지까지 한글로 적혀 있습니다. 복사 버튼으로 그대로 가져갈 수 있어서 문제를 찾거나 공유할 때 편해요. 기록은 메모리에만 저장되며 새로고침하면 사라집니다.

## 참고

- Chat Completion API에서만 동작합니다.
- 시스템 메시지나 유저 메시지가 마지막인 상태에서는 이어쓰기를 하지 않습니다.
